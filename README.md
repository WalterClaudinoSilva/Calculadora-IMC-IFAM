# 🟢 Calculadora de IMC - IFAM Campus Manacapuru

![Versão Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)
![Kotlin](https://img.shields.io/badge/kotlin-%237F52FF.svg?style=for-the-badge&logo=kotlin&logoColor=white)

Este projeto é um material didático desenvolvido para os alunos do **Instituto Federal do Amazonas (IFAM) - Campus Manacapuru**. Ele consiste em uma calculadora de Índice de Massa Corporal (IMC) moderna, seguindo a identidade visual institucional.

## 🎯 Objetivos de Aprendizagem
- Desenvolvimento de interfaces Android com **XML e Material Design**.
- Implementação de lógica de programação com **Kotlin**.
- Manipulação de entradas de usuário e validação de dados.
- Aplicação de temas e cores institucionais (Verde e Amarelo IFAM).

## ✨ Funcionalidades
- [x] Entrada de Peso (kg) e Altura (m).
- [x] Entrada de Idade para fins estatísticos.
- [x] Cálculo automático do IMC ao clicar no botão.
- [x] Interface responsiva e acessível.
- [x] Validação de campos vazios.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Kotlin
- **IDE:** Android Studio (Ladybug ou superior)
- **Interface:** XML (ConstraintLayout)
- **Min SDK:** 24 (Android 7.0 Nougat)

## 🚀 Como utilizar este projeto
Para os alunos que desejam praticar:

1. Faça o **Download ZIP** ou clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/Calculadora-IMC-IFAM.git
   ```
2. Abra o **Android Studio**.
3. Vá em `File > Open` e selecione a pasta do projeto.
4. Aguarde a sincronização do Gradle.
5. Execute em um emulador ou dispositivo físico.
